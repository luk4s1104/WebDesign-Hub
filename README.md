# 🌐 webdesign-hub

Repositório centralizador da disciplina de **Web Design**. Este repositório funciona como um índice estruturado para organizar os materiais didáticos e direcionar o acesso aos projetos práticos desenvolvidos ao longo do curso.

## 🎯 Objetivo

*   **Armazenamento de Arquivos:** Centralizar slides, notas de aula e códigos de exemplo fornecidos pelo professor.
*   **Indexação de Projetos:** Servir como um guia (Hub) que conecta e redireciona para os repositórios individuais de cada site ou aplicação web criados na matéria.
